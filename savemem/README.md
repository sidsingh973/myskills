# /savemem

Saves the current Claude Code session to `~/.claude/session_memory.md` so you can resume it later.

## Install

```bash
mkdir -p ~/.claude/skills/savemem && curl -fsSL https://raw.githubusercontent.com/sidsingh973/myskills/main/savemem/SKILL.md -o ~/.claude/skills/savemem/SKILL.md
```

Restart Claude Code, then use `/savemem` in any session.
