# /prevmem

Loads the previously saved session from `~/.claude/session_memory.md` so you can pick up where you left off.

## Install

```bash
mkdir -p ~/.claude/skills/prevmem && curl -fsSL https://raw.githubusercontent.com/sidsingh973/myskills/main/prevmem/SKILL.md -o ~/.claude/skills/prevmem/SKILL.md
```

Restart Claude Code, then use `/prevmem` in any session.
