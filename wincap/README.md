# /wincap

Takes a screenshot of your screen and lets Claude analyze what's on it.

## Install

```bash
mkdir -p ~/.claude/skills/wincap && curl -fsSL https://raw.githubusercontent.com/sidsingh973/myskills/main/wincap/SKILL.md -o ~/.claude/skills/wincap/SKILL.md
```

Restart Claude Code, then use `/wincap` in any session.
